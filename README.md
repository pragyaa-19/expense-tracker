# Smart Expense Manager

A full-stack expense management application built with Django REST Framework, PostgreSQL, React, and Vite.

## 🚀 Live Demo

👉 https://smart-expense-manager-web.vercel.app/

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Bootstrap
- Axios
- React Router

### Backend
- Python
- Django
- Django REST Framework
- JWT Authentication
- PostgreSQL

### Deployment
- Frontend: Vercel
- Backend: Render

## ✨ Features

- User registration and login
- JWT authentication
- Add and manage expenses
- Expense reports
- Monthly and yearly expense history
- Expense charts
- Budget tracking
- Receipt upload
- Profile management
- Dark/light theme
